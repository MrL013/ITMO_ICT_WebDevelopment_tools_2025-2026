# Документация по лабораторным работам

В этой документации объединены три проекта:

- `lab1` — Реализация серверного приложения FastAPI
- `lab2` — Потоки. Процессы. Асинхронность
- `lab3` — Упаковка FastAPI приложения в Docker, Работа с источниками данных и Очереди

## Как устроена документация

Для каждой лабораторной работы выделен отдельный раздел:

- `Lab1` — обзор, API и запуск
- `Lab2` — обзор, задания и запуск
- `Lab3` — обзор, API, запуск и отдельная страница с PowerShell-командами

## Кратко по содержанию

### Lab1

Проект с FastAPI, PostgreSQL, SQLAlchemy и Alembic, реализующий веб-приложение для поиска попутчиков.

### Lab2

Две задачи:

- сравнение подходов `threading`, `multiprocessing` и `asyncio` на вычислениях
- параллельный парсинг веб-страниц с сохранением результатов в базу данных

### Lab3

Развитие предыдущих лабораторных:

- упаковка в Docker
- выделение парсера в отдельный сервис
- синхронный вызов парсера через HTTP
- асинхронный вызов парсера через `Celery + Redis`
